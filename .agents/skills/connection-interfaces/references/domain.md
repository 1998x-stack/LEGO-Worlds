# connection-interfaces — domain notes

A virtual graph port is an engineering placement reference, not a physical socket. For stud/socket account for 1.7 mm stud protrusion in mating transforms; for Technic joints distinguish spin axis from insertion depth. Some current wheel/gear interfaces are schematic.
