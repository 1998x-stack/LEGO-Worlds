# Codex project skills

Codex **officially discovers repo-local skills under `.agents/skills`**, not `.codex/skills`. The `.codex/skills` entries are documentation/compatibility mirrors only; each points at its canonical skill. Use `$<skill-name>` or `/skills` with Codex after opening this repo. Root `AGENTS.md` sets durable policy.

Run `npm run test:skills`. Do not add undocumented model config defaults or secrets here.
